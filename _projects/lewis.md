Lewis is a small studio that makes brand films and campaigns. They wanted a website that felt as bold as their work, not a template with a logo on it.

I designed a dark, high-contrast home page around one striking 3D sphere, then built it by hand in Javascript with a light PHP back end for the contact form and the case studies. Pages load fast, and the studio can add new work without calling me.

## The brief

Lewis had outgrown a template site. They wanted something that looked like their films: dark, confident, with one idea doing the work. They also wanted to publish case studies without sending me a message each time.

## What I built

The home page is a single scene built around a 3D sphere, with the studio name beside it and little else competing. Below it, the case studies load as simple pages with large images and short write-ups.

The contact form and the case-study list run on a small PHP back end. Adding a project means filling in a short form and uploading images, so the studio handles it themselves.

I kept the pages light on purpose. The sphere loads as one compressed image and the rest is plain HTML, CSS and a little Javascript, so the site opens quickly on a phone.
